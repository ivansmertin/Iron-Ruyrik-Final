# Дизайн-система «Железный Рюрик»

## Основа бренда

Интерфейс продолжает существующую айдентику зала: глубокий чёрный фон, яркий жёлтый акцент, белая типографика и крупные числовые показатели. Персонаж Рюрика остаётся в логотипе; остальной UI — современный, спокойный и утилитарный.

Основной логотип для приложения — горизонтальный знак «персонаж + словесный знак» из `2 (5).png`. В интерфейсе он показывается как CSS-crop исходного изображения, поэтому оригинальный файл не изменяется. Для компактных аватаров используется квадратный знак из того же исходника. Фотографии тренеров не создаются: применяются брендированные буквенные placeholders.

## Цвета

Цвета получены sampling-ом плоских областей оригинальных PNG:

| Token | Значение | Назначение |
| --- | --- | --- |
| `--brand-yellow` | `#FFD626` | главный CTA, active state, ключевые числа |
| `--brand-yellow-pressed` | `#E8BE00` | pressed/hover для жёлтой кнопки |
| `--brand-black` | `#111111` | основной фон, соответствует ассетам |
| `--surface-1` | `#191919` | карточки |
| `--surface-2` | `#202020` | вложенные поверхности и controls |
| `--surface-3` | `#282828` | hover/selected neutral |
| `--border-dark` | `#2F2F2F` | границы карточек и полей |
| `--text-primary` | `#F7F7F5` | основной текст |
| `--text-secondary` | `#A8A8A3` | подписи и вторичный текст |
| `--text-muted` | `#777773` | disabled и служебные подписи |
| `--status-positive` | `#7CCB88` | достаточное число мест, позитивная динамика |
| `--status-warning` | `#F0B84A` | почти заполнено; не конкурирует с brand yellow |
| `--status-danger` | `#E16B62` | отмена, ошибка, закрытый интервал |

Жёлтый используется с чёрным текстом. Жёлтый текст на белом не применяется.

## Типографика

- Гарнитура: `Onest`, единая для всего продукта; web-font с системным fallback.
- Body: 16px / 1.5, weight 400–500.
- Labels: 13–14px / 1.35, weight 500–600.
- Page title: 28–40px, weight 700.
- Крупные числа: 40–64px, weight 750–800, tabular numerals.
- Кнопки: 14–16px, weight 700, без искусственного letter-spacing кроме коротких uppercase CTA.

## Spacing

Базовый шаг 4px. Scale: `4, 8, 12, 16, 20, 24, 32, 40, 48, 64`.

- Mobile page gutter: 16px.
- Tablet/desktop page gutter: 24–32px.
- Вертикальный ритм секций: 24–32px.
- Внутренние отступы карточек: 16–24px.

## Геометрия

- Карточки: 16px radius.
- Кнопки и form controls: 12px radius.
- Chips/date cells: 10–12px radius.
- Avatar/logo mark: 14px либо круг только для компактного profile avatar.
- Максимум одна крупная скруглённая поверхность на смысловой блок; не использовать pill-форму повсеместно.

## Surfaces и borders

- Основной фон — `--brand-black`.
- Карточки — `--surface-1`, граница 1px `--border-dark`.
- Вложенные строки — `--surface-2`; hover — `--surface-3`.
- Тень только для fixed bottom navigation и модальных слоёв, без glow.

## Кнопки

- Primary: жёлтый фон, чёрный текст, min-height 52px, уверенная ширина.
- Secondary: `--surface-2`, белый текст, тонкая граница.
- Ghost: прозрачный фон, белый текст, hover surface.
- Danger: приглушённый красный фон/граница, светлый текст.
- Disabled: серый фон и текст, `cursor: not-allowed`, без снижения opacity ниже читаемого уровня.
- Focus: внешний outline 3px с полупрозрачным жёлтым кольцом.

## Карточки

- Карточка записи: дата/время как главный контент, затем тип тренировки и тренер, один релевантный action.
- Time slot: время слева, capacity и короткая подпись справа; заполненный слот не интерактивен.
- Trainer card: branded placeholder, имя, реальные направления, CTA.
- Stat card: один показатель, одно значение, максимум одна подпись динамики.

## Иконки

- Только Lucide, stroke 1.8–2px.
- Размеры 18, 20 или 22px; в mobile nav — 21px.
- Иконка всегда сопровождает действие или помогает навигации; декоративные иконки не добавляются.

## Form controls

- Min-height 48px, тёмная поверхность, 1px border.
- Label расположен над control.
- Selected radio/card получает жёлтую границу и небольшую жёлтую метку.
- Ошибка описывается естественным русским текстом рядом с control.

## Loading, empty и feedback states

- Skeleton: прямоугольные блоки без shimmer-glow, мягкая смена оттенка surface.
- Empty state: короткое объяснение и один следующий шаг.
- Toast: компактный, снизу над navigation; success — светлый текст и зелёная метка, error — красная метка.
- Success booking: крупная check-иконка, дата/время, понятные действия.

## Layout principles

- Mobile-first; ключевой сценарий записи виден без обучения.
- Client app: centered shell до 1180px; рабочий контент обычно 720–900px.
- Desktop: боковая продуктовая навигация и основная колонка, без растягивания mobile cards.
- Admin: отдельный desktop-first shell до 1440px с компактной sidebar и таблицей.
- Grid применяется только там, где повышает читаемость; маркетинговых hero-блоков нет.

## Mobile bottom navigation

- Fixed снизу, пять разделов: Главная, Запись, Тренеры, Прогресс, Профиль.
- Высота не менее 72px плюс safe-area inset.
- Активный пункт — жёлтая иконка и текст.
- Каждый touch target минимум 56×52px.
- `/admin` отсутствует в mobile navigation.
