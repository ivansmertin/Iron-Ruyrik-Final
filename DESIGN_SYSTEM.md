# Дизайн-система «Железный Рюрик»

## Основа бренда

Интерфейс продолжает айдентику зала: глубокий тёмный холст (`#111111`), яркий жёлтый акцент (`#FFD626`), белая типографика (`#FFFFFF`) и строгий системный ритм. Персонаж Рюрика остаётся в логотипе; остальной UI — современный, спокойный, сдержанный и утилитарный.

Основной логотип для приложения — горизонтальный знак «персонаж + словесный знак» из `2 (5).png`. В интерфейсе он масштабируется через внутренние элементы с сохранением сенсорной области ссылки не менее 44×44 CSS px.

## Типографика

- Гарнитура: `Onest`, единая для всего продукта; начертания 400, 500, 600, 700, 800.
- Page title: `clamp(28px, 5vw, 32px)`, line-height 1.1, weight 800.
- Hero metric / time: `clamp(44px, 8.5vw, 52px)`, line-height 1.0, weight 850, `font-variant-numeric: tabular-nums`.
- Section title: `clamp(18px, 4vw, 20px)`, line-height 1.25, weight 750.
- Body: 16px (`1rem`), line-height 1.5, weight 400–500.
- Metadata: 13px (`0.8125rem`, диапазон 12–14px), tabular numerals.
- Все заголовки и текстовые блоки снабжены `overflow-wrap: break-word; word-break: break-word;` для предотвращения горизонтального переполнения.

## Spacing и вертикальный ритм

Базовый шаг: системный ритм `4, 8, 12, 16, 24, 32, 48` px.
- `--space-1`: 4px
- `--space-2`: 8px
- `--space-3`: 12px
- `--space-4`: 16px
- `--space-6`: 24px
- `--space-8`: 32px

Исключено накопление двойных отступов: вертикальный паддинг контейнеров `.ui-section` равен `0`, а расстояние между смежными секциями строго управляется `margin-top: var(--space-6)` (24px) или `.ui-section--spacious` (32px).

## Геометрия и радиусы (Radii)

- `--radius-none`: `0px` — контентные блоки, карточки без рамок, разделители.
- `--radius-card`: `0px` — упразднение устаревших скруглений контента.
- `--radius-sm`: `2px` — бейджи статусов, микро-индикаторы.
- `--radius-control`: `4px` — кнопки, поля ввода, интерактивные строки, чекбоксы, тосты.
- `--radius-modal`: `8px` — унифицированные модальные окна.
- Устаревшие литералы 12px, 14px, 16px, 20px устранены из общих стилей.

## Интерактивные контролы и Touch Targets

- Первичные кнопки (`.button--primary`): высота 48–52px, минимальная ширина гарантирует удобный тап.
- Вторичные кнопки, ссылки назад (`.back-link`), иконки закрытия (`.modal__close`, `.icon-button`): тач-таргет строго $\ge 44\times 44$ CSS px.
- Логотип в мобильном хедере: сенсорная область ссылки сохраняет высоту $\ge 44$ px (54px), уменьшение визуального знака выполнено без масштабирования тега ссылки.
- Состояния кнопок:
  - Обычный disabled: `opacity: 0.5; cursor: not-allowed;`
  - Подтверждённое состояние (`.button--confirmed`): сохраняет `opacity: 1 !important;`, фоновый цвет `--brand-yellow`, текст `#111111` на протяжении всей 350ms фиксации перед переходом.
  - Submitting: `opacity: 0.85; cursor: wait;`

## Нижняя мобильная навигация (Mobile Bottom Nav)

- Фиксированная панель снизу, 5 разделов: Главная, Запись, Тренеры, Прогресс, Профиль.
- Высота: `calc(60px + env(safe-area-inset-bottom, 0px))`.
- Фон: `--brand-black` (`#111111`).
- Активный пункт: цвет `--brand-yellow` (`#FFD626`), верхний индикатор.
- Неактивные пункты: цвет `--text-tertiary` (`#929292`), контраст к фону 4.68:1 ($\ge 4.5:1$ WCAG AA).
- Размер шрифта подписи: 12px (`0.75rem`), начертание 600, защита от переноса строк `ellipsis`.
- Физический размер тач-таргета каждого пункта: $\ge 48\times 44$ CSS px.

## Модальные окна (Modal System)

- Полная унификация `.modal` и `.modal-content`:
  - Радиус скругления: `--radius-modal: 8px;`
  - Внутренние отступы: 20px.
  - Ширина: `min(100%, 398px);`
  - Максимальная высота: `calc(100dvh - max(32px, env(safe-area-inset-top, 0px) + env(safe-area-inset-bottom, 0px)))`.
  - Единая тень: `0 16px 40px rgb(0 0 0 / 60%)`.
  - Кнопка закрытия: размер $\ge 44\times 44$ px, радиус 4px.
  - Доступность: изоляция внешнего фонового DOM при открытии окна (`aria-hidden="true"` и `inert` для соседних элементов относительно диалога с восстановлением при закрытии), сохранение фокус-трапа по Tab и закрытия по Escape / Android Hardware Back.
