# Issue: Предварительный просмотр доступности тренеров в расписании (Trainer Slot Availability Preview)

**Статус**: Open (Product/Preview Limitation)  
**Компонент**: Backend (`app.services.schedule`) / Product  
**Обнаружено на этапе**: M07 / M12 (Visual Migration «Железный Рюрик»)  
**Дата**: 12.09.2026  

---

## 1. Фактическое состояние реализации
- **Бэкенд-валидация при записи**: В методе `BookingService.create` (`backend/app/services/booking.py`, строки 69–70) **присутствует строгая проверка занятости тренера**:
  `if trainer and bookings.trainer_has_overlap(trainer.id, start_at, end_at): raise DomainError("TRAINER_NOT_AVAILABLE", "Тренер уже занят в это время.", 409)`
  Бэкенд надёжно защищает от двойного бронирования одного тренера в один и тот же временной слот.
- **Ограничение публичного расписания (`GET /api/v1/schedule`)**: Публичный endpoint расписания возвращает слоты с агрегированной загрузкой зала (`booked` / `capacity`), но не вычисляет и не возвращает статус персональной занятости каждого тренера на этапе предварительного просмотра дней.

## 2. Честное отражение в UI
- На экране профиля тренера (`TrainerPage.tsx`) блок слотов озаглавлен «БЛИЖАЙШЕЕ ВРЕМЯ В ЗАЛЕ», без ложного обещания персонального расписания тренера в этот час.
- На главной странице (`HomePage.tsx`) свободный слот описывается честно: «{duration} мин · Тренер или самостоятельно».
- Если тренер не входит в поддерживаемый контракт бронирования (например, приглашенный тренер Сергей), UI честно блокирует кнопку записи с пояснением: «Запись к этому тренеру через приложение временно недоступна».
- При попытке забронировать уже занятого тренера (409 `TRAINER_NOT_AVAILABLE`) форма бронирования выводит понятную ошибку сервера без сбоя приложения.

## 3. Рекомендации для Product/Backend
1. Расширить схему `ApiSlot` полем `bookedTrainerSlugs: string[]` или `availableTrainerSlugs: string[]` в `ScheduleService.get_schedule`.
2. В интерфейсе расписания фильтровать или дизейблить слоты, где выбранный тренер уже забронирован другим клиентом, до клика по кнопке бронирования.
