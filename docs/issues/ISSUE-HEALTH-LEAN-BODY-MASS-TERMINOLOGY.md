# Issue: Корректная терминология состава тела (Lean Body Mass vs Muscle Mass)

**Статус**: Resolved in UI (Documented Contract)  
**Компонент**: Health Bridge / Frontend Progress / Backend Schema  
**Обнаружено на этапе**: M02 / M08 / M12 (Visual Migration «Железный Рюрик»)  
**Дата**: 12.09.2026  

---

## 1. Описание проблемы
В первоначальной версии приложения показатель состава тела `lean_body_mass` из HealthKit / Health Connect (`LeanBodyMassRecord`) и весов Xiaomi Scale S400 ошибочно подписывался как «Мышечная масса».
В биоимпедансометрии и спортивной физиологии:
- **Lean Body Mass (LBM)** = общая безжировая масса тела (включает скелетные мышцы, внутренние органы, костную ткань и воду).
- **Skeletal Muscle Mass (SMM)** = скелетно-мышечная масса (только поперечно-полосатая мускулатура).

Подмена LBM понятием «Мышечная масса» завышала реальный объем мышц атлета на 15–20 кг, что вызывало недоумение у тренирующихся.

## 2. Решение в UI
- На всех экранах (`ProgressPage.tsx`, `HealthSourcesModal.tsx`, `healthBridge.ts`) показатель строго именуется: **«Безжировая масса»**.
- В схеме данных бэкенда каноническое поле сохранено как `lean_body_mass` без мутаций.
